# 📈 Stock Market Analysis & Prediction using AI

An end-to-end Machine Learning and Deep Learning project that analyzes historical stock market data and explores stock price prediction using Python.

The project also includes an interactive Streamlit dashboard for stock analysis, visualization, machine learning predictions, and intraday market monitoring.

## 🚀 Project Overview

This project focuses on analyzing historical stock market data, initially using Reliance Industries (NSE), and predicting stock prices using Machine Learning and Deep Learning techniques.

It includes data cleaning, exploratory data analysis, feature engineering, model training, evaluation, and visualization.

An interactive web dashboard allows users to analyze multiple Indian stocks, view historical trends, monitor intraday prices, and explore experimental price predictions.

## 🎯 Project Objectives

- Analyze real historical stock market data.
- Understand stock price trends and patterns.
- Perform data cleaning and preprocessing.
- Apply Machine Learning algorithms.
- Explore Deep Learning using LSTM.
- Compare model performance using evaluation metrics.
- Build an interactive stock market analysis dashboard.

## 🤖 Machine Learning Models

1. Linear Regression
2. Random Forest Regressor
3. LSTM (Long Short-Term Memory)

## 📉 Model Evaluation

Models are evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score
