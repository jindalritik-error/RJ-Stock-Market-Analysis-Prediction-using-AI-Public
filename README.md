# 📈 Stock Market Analysis & Prediction using AI

An end-to-end Machine Learning and Deep Learning project that analyzes historical stock market data and explores stock price prediction using Python.

## 🚀 Project Overview

This project focuses on analyzing historical stock market data of Reliance Industries (NSE) and predicting the next trading day's closing price using Machine Learning and Deep Learning techniques.

The project includes data cleaning, exploratory data analysis, feature engineering, model training, evaluation and visualization.

## 🎯 Project Objectives

- Analyze real historical stock market data.
- Understand stock price trends and patterns.
- Perform data cleaning and preprocessing.
- Apply Machine Learning algorithms.
- Explore Deep Learning using LSTM.
- Compare model performance using evaluation metrics.

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- TensorFlow / Keras
- Yahoo Finance (yfinance)
- Google Colab
- Streamlit

## 📊 Dataset Information

**Stock:** Reliance Industries Limited (NSE)

**Ticker:** RELIANCE.NS

**Data Period:** 5 Years

**Data Frequency:** Daily

Dataset features include:

- Date
- Open
- High
- Low
- Close
- Volume

## 🤖 Machine Learning Models

1. Linear Regression
2. Random Forest Regressor
3. LSTM (Long Short-Term Memory)

## 📉 Model Evaluation

Models are evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

Actual model results will be added after final validation.
